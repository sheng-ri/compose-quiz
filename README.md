# compose考试

## 本 App 目标

将《JetpackCompose1.8Essentials》书中的习题做成一个 App，以便我以后在坐公交车的时候可以随时拿出来刷刷题，巩固 compose 基础知识。

## 本 App 核心功能

主要包括三个，第一个是章节习题，第二个是收藏集，第三个是每日练习。

章节习题就是显示《JetpackCompose1.8Essentials》中所有的章节，点进去章节可以进行该章节的习题测试，所有习题都做完之后，会显示最终结果。最终结果中，每个题目有个收藏功能，收藏后就能将该题收藏进收藏集。

收藏集收藏了所有收藏的习题，可以在这里根据章节、收录顺序排序所有习题。收藏集也提供测试功能，设置测试数量，就能从收藏的题目中随机抽取这些数量的题目进行测试。测试做完之后，会显示最终结果，可以在最终结果页面取消收藏。

每日练习就是从所有题库中随机抽取一定数量进行测验。测试做完之后会显示最终结果，可以在最终结果页面取消收藏或收藏。每日练习里面会记录答错次数，可以浏览答错次数从高到低的题目列表，这些题目也可以收藏或取消收藏。每日练习完成之后，可以在日历中给今天打一次卡。

另外有个隐藏功能，就是题目的录入。建议使用 Excel 导入。后期如果有能力给 App 开发 Web 端口再做个一个 Web 新增题目的功能。或者做个后端，存放题目。
